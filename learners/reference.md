## Glossary

Argument
:   A value you pass into a function when you call it, such as `'Jack'` in `greet('Jack')`.

Boolean
:   A value that is either `True` or `False`.

Class
:   A blueprint for creating objects. It groups data (attributes) and behaviour (methods).

Compiler
:   A program that translates a whole program into machine code before it runs.

Dictionary
:   A collection of key-value pairs, such as `{'name': 'Jack', 'age': 25}`.

Exception
:   An error that happens while a program runs. You can handle it with `try` and `except`.

Function
:   A named block of code that you can run (call) many times. You define one with `def`.

Index
:   The position of an item in a sequence. Python counts from 0.

Interpreter
:   A program that runs code step by step without making a separate machine-code file first. Python uses an interpreter.

List
:   An ordered collection that you can change, such as `[1, 2, 3]`.

Loop
:   Code that repeats. `for` goes through each item of a sequence; `while` repeats while a condition is `True`.

Module
:   A `.py` file whose code you can `import` into another file.

Object
:   One value made from a class. In Python every value is an object.

Package
:   A folder of modules, or a library you install with `pip`.

Paradigm
:   A style of programming, such as imperative, object-oriented, functional or logic programming.

Parameter
:   The name a function uses for a value it receives, such as `name` in `def greet(name):`.

Pseudocode
:   A plan for a program written in plain English before you write the code.

Set
:   A collection of unique items with no order.

String
:   Text, written inside quotes, such as `'Hello'`.

Tuple
:   An ordered collection that cannot be changed, such as `(1, 2, 3)`.

Variable
:   A name that refers to a value, such as `age = 25`.
